# Media Kit · Val Gómez

Landing estática lista para GitHub Pages.

1. Crea un repositorio en GitHub (por ejemplo `mediakit`).
2. Sube `index.html` y la carpeta `img/` tal cual.
3. Ve a Settings › Pages › Source: rama `main`, carpeta `/ (root)` y guarda.
4. En un par de minutos la página queda en `https://TU-USUARIO.github.io/mediakit/`.

Para cambiar una foto, reemplaza el archivo en `img/` con el mismo nombre.
